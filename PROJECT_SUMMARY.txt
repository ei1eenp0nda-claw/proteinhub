📋 项目概述
─────────────
ProteinHub 是一个面向生物信息学研究者的蛋白质数据管理平台，
采用多代理协作开发模式完成。

🚀 快速开始
───────────
1. 进入项目目录:
   cd /root/workstation/protein_local/proteinhub_v2

2. 一键启动:
   ./start.sh

3. 访问应用:
   • 前端: http://localhost:5173
   • API:  http://localhost:8000
   • 文档: http://localhost:8000/docs

🐳 Docker部署
─────────────
cd docker
docker-compose up -d

访问 http://localhost 即可使用。
