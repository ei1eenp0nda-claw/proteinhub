📋 项目概况
────────────────────────────────────────────────────────────────────────
项目名称:    ProteinHub
版本:        v1.0.0
类型:        Web应用 (前后端分离)
用户系统:    ✅ 支持用户注册/登录/认证
部署方式:    Docker + Docker Compose

✨ 核心功能
────────────────────────────────────────────────────────────────────────
✅ 用户认证系统
   • 用户注册 / 登录
   • JWT Token 认证
   • 个人中心

✅ 蛋白质数据管理
   • 蛋白质列表展示
   • 详细信息查看
   • 搜索功能 (名称、物种、功能)

✅ 收藏功能
   • 添加收藏
   • 取消收藏
   • 收藏列表

✅ 响应式设计
   • 支持桌面端和移动端
   • 现代化UI界面

🛠️ 技术栈
────────────────────────────────────────────────────────────────────────
后端:
  • Python 3.11+
  • FastAPI (现代异步Web框架)
  • SQLAlchemy (ORM)
  • SQLite (数据库)
  • Pydantic (数据验证)
  • JWT (认证)

前端:
  • React 18
  • TypeScript
  • Vite (构建工具)
  • Tailwind CSS (样式)
  • React Router (路由)
  • Axios (HTTP客户端)

部署:
  • Docker
  • Docker Compose
  • Nginx
  • GitHub Actions (CI/CD)

🚀 快速开始
────────────────────────────────────────────────────────────────────────
1. 进入项目目录:
   cd /root/workstation/protein_local/proteinhub

2. 一键启动:
   ./start.sh

3. 访问应用:
   🌐 前端: http://localhost:5173
   🔧 API:  http://localhost:8000
   📚 文档: http://localhost:8000/docs

🐳 Docker部署
────────────────────────────────────────────────────────────────────────
cd docker
docker-compose up -d

访问 http://localhost 即可使用。
